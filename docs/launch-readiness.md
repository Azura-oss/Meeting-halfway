### 🔴 安全发现：`cloudfunctions/` 会被打进小程序包（2026-10-15 02:45）

- **实测确认**：在 `cloudfunctions/` 内放入 200 KB 探针文件后，预览包体从 **95.1 KB → 290.4 KB**，说明云函数目录确实进入小程序包。
- **风险**：任何放在 `cloudfunctions/` 下的密钥文件都会随预览版/体验版下发到客户端。
- **处置**：
  - 已删除 `cloudfunctions/{searchPOI,getRecommendations,getRoutes}/config.json`（含腾讯位置服务 Key）；密钥继续只保存在云函数环境变量侧。
  - 已尝试把 `cloudfunctions` 加入 `packOptions.ignore` 并重载项目配置（`cli close` + `cli open`）—— **实测无效**，探针仍使包体升至 290.4 KB。打包器会强制包含 `cloudfunctionRoot`。该条目保留作兜底，但**不可依赖**。
  - 新增回归测试「云函数目录内不得存放任何含密钥的文件」，守住真正的漏洞点。
- **遗留**：`cloudfunctions/` 内的服务端源码与种子数据仍会随包下发（非密钥，属信息暴露）。彻底隔离需把项目改为 `miniprogramRoot: "miniprogram/"` 的两层结构，属较大改动，本轮不做。
- **建议**：地图 Key 曾随 02:13、02:28 两次预览包下发到测试机。若不放心，可在腾讯位置服务控制台重置该 Key 并重新配置云函数环境变量。

### 本轮真机回归发现与处理（2026-10-15 02:25）

- [x] **已修复：推荐结果落在几公里外（真 bug）**。腾讯 `boundary=nearby` 在半径内无匹配时会被忽略并返回远端兜底结果（实测 `keyword=滑雪` + 1000m 半径，仍返回 3276~9629m 的场所）。后果是「1km 空 → 自动扩到 5km」与空态提示**永远不会触发**。已在 `getRecommendations.searchPlaces()` 加二次距离过滤（`haversine <= radius * 1.1`）。修复后 `滑雪` 正确识别 1km 空并扩展至 5km，返回 2 个真实滑雪场馆；`咖啡厅` 仍为 139~225m。
- [x] **已修复：收藏报「该地点已不存在」**。根因是推荐结果已是真实 POI ID，而收藏仍走 Mock，Mock 在自身种子表中查不到这些 placeId 于是返回 404。
- [x] **隐私声明已确认可用**：真机可正常录音并识别成文字。未弹出隐私协议弹窗属开发者/预览版差异，不影响功能。

## 提审材料（可直接复制）

### 版本号

`1.0.0`

### 功能页面说明

1. 首页：填写 2~6 位参与人的出发地（支持语音输入或手动搜索联想），并为每人选择出行方式。
2. 偏好页：选择本次聚会想去的地点类型（可多选）。
3. 结果页：展示群体出行的折中碰面点与附近候选场所，可在地图上标出各参与人的到达路线，支持收藏与置顶。
4. 店铺详情：展示场所基本信息与各参与人的到达情况，支持导航与收藏。
5. 收藏页 / 历史页：查看已收藏的场所与历史搜索记录。

### 审核备注（建议填写，可显著降低驳回率）

- 本小程序为「多人聚会折中点推荐」工具，需要输入 **2~6 位参与人的出发地** 后才能计算折中点，**单人无法跑通完整流程**。
- 建议体验路径：首页输入任意两个成都地点（例如「天府广场」「春熙路」）→ 为两人选择出行方式 → 点下一步选择任意偏好 → 查看推荐结果。
- 语音输入需授权麦克风；也可以完全使用手动输入，不影响体验。
- 地图仅用于展示碰面点与到达路线，**不采集用户实时定位**（无 `wx.getLocation`）。
- 若需固定测试数据，可使用成都任意两个地点，服务端已配置真实地图服务。
